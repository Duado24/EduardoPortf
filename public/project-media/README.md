These assets were prepared locally on October 10, 2026. Full source and capture details are in `provenance.json`.

- **autocanv.webp:** The actual supplied React UI, using offline scanner/formatter output for an existing synthetic test example. The screenshot explicitly labels the data as a demonstration. The displayed counts describe that fixture; they are not adoption or performance metrics. No live Canvas operations occurred.

A neutral host wrapper supplies presentation and local tab switching. This illustrates a source pattern; it is not a live professional course screenshot or a separate Ensign template project package.

No credentials, private backups, course reports, institutional course content or personal information were used. AutoCanv backend/client code was excluded from the isolated capture workspace. Browser captures blocked non-local requests and disabled write operations. The screenshots were compressed to WebP without changing their visible content.
